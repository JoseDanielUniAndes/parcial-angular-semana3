# El aroma mágico — Evaluación Práctica Angular (MISW4104)

Aplicación Angular que muestra las variedades de café disponibles en una tienda de café, consumiendo un listado JSON por HTTP.

Proyecto base generado con [Angular CLI](https://github.com/angular/angular-cli) 19.2 usando módulos (`NgModule`, sin componentes standalone).

## Requisitos

- Node.js 20 o superior (probado con Node 22)
- npm 10 o superior
- Google Chrome (para las pruebas con Karma)

## Instalación

```bash
npm ci
```

## Ejecución

```bash
npm start
```

Abrir `http://localhost:4200/`. La aplicación recarga al guardar cambios.

## Pruebas

```bash
npm test
```

## Compilación

```bash
npm run build
```

El resultado queda en `dist/parcial-angular/`.
